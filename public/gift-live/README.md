# Donguriko TikTok ギフト反応画面（試作）

既存の `Donguriko Live_AI配信アバター` の `public/gift-live/` に組み込み済みです。既存システムを `start-tiktok.bat` で起動して、OBS のブラウザソースを `http://127.0.0.1:8790/gift-live/index.html?obs=1`、1080×1920 に設定します。実際のポートが違う場合は起動ログの `OBS URL` に合わせます。

既存の TikTok 接続、ギフト名の変換、Gemma の返答生成、Donguriko の TTS を利用します。新しい画面は `/events` から状態を受け取り、ギフトの種類で表情動画を切り替え、音声の音量データで口元の差分を出します。OBS で音声を使う場合は既存の `config.json` で `audio.playInBrowser` を `true` にし、OBS の「音声をOBSで制御する」を有効にします。

**画質上の制限:** Imagegen が生成した複数の静止画を補間した試作動画です。手と顔の中間フレームに歪みが出るため、動画レベルの完成素材としては使用しないでください。自然な動きには画像から動画を生成するモデルでクリップを作り、`avatar-idle.mp4` と `avatar-loop.mp4` を置き換える必要があります。現在接続されている vidIQ の動画生成は必要な120クレジットが不足しており、生成は実行されず課金もされていません。
