# assets

キャラクター「どんぐりこ」の立ち絵・表情・背景を置く場所です。

アプリが読むのは次のファイルです（リポジトリに入っています）。

- `donguriko-face-neutral-atlas.webp` / `donguriko-face-blink-atlas.webp` / `donguriko-face-mouth-open-atlas.webp`
- `donguriko-imagegen-body-spritesheet.webp`
- `donguriko-forest.png`（背景）

元画像や動画（`donguriko.mp4`、`*-source.png`、`*-hd.png` など）は、サイズが大きく実行にも不要なため入れていません。

Live2Dモデル（`public/live2d/Donguriko/`）を使う場合は、別途 Live2D Cubism Core（`public/vendor/live2dcubismcore.min.js`）が必要です。Live2D社の独自ライセンスのため再配布できません。公式サイトから取得してください。
