# assets

キャラクター「どんぐりこ」の画像・動画素材（合計70MB超）は、サイズの都合でリポジトリに含めていません。
動かすには、このフォルダに以下を置いてください。

- `donguriko.mp4`
- `donguriko-tall-spritesheet.png` / `.webp`
- `donguriko-body-only-spritesheet.png` / `.webp`
- `donguriko-forest.png`

Live2Dモデル（`public/live2d/Donguriko/`）は含まれていますが、
実行には Live2D Cubism Core（`public/vendor/live2dcubismcore.min.js`）が別途必要です。
こちらは Live2D社の独自ライセンスのため再配布できません。公式サイトから取得してください。
